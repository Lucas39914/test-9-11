# hello Lucas 弹窗

一个最小的 Python 项目：运行时弹出一个对话框显示 `hello Lucas`。

## 环境要求

- Python 3（需要包含 tkinter，Windows 官方安装包默认自带）

## 运行

```bash
python hello.py
```

运行后会弹出一个标题为 `hello Lucas` 的对话框，内容为 `hello Lucas`，点击「确定」即可关闭。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `hello.py` | 主程序，使用标准库 `tkinter.messagebox` 弹出提示框 |
